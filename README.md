# Smartarget Whatsapp Chat

Allow customers to contact you by using Whatsapp Chat on your website

## FAQ

- How can I create the Whatsapp setup?
Simply follow this link: [https://app.smartarget.online/#/preview/webiste/whatsapp](https://app.smartarget.online/#/preview/webiste/whatsapp)

- Where do I get the Smartarget ID? 
At the upper area in your Smartarget account: [https://app.smartarget.online/#/integration](https://app.smartarget.online/#/integration)


## Installation

1. Download `template.tpl` from this repository
2. Open Google Tag Manager → **Templates** → **New** (Tag Templates)
3. Click the three-dot menu → **Import**
4. Upload `template.tpl` and save

## Usage

1. Create a new tag using the Smartarget template
2. Enter your Smartarget ID
3. Add a trigger (typically Page View - All Pages)
4. Save and publish
